# Eliab López

**Full Stack Engineer** · Cartagena, Colombia · remoto

5 años construyendo y operando aplicaciones web y móviles en sectores regulados: pensiones, seguros y salud. Mi base es TypeScript, React y Node.js. Hoy trabajo en una plataforma de pagos y cálculo del sistema pensional colombiano, de punta a punta: requerimientos, arquitectura, implementación, pruebas y soporte en producción.

También diseño flujos de desarrollo con agentes (Claude Code) para diagnosticar incidencias, especificar requerimientos y validar pruebas.

## Stack

- **Frontend:** React, Next.js, TypeScript, React Native, TanStack Query, Zustand, Tailwind CSS, shadcn/ui
- **Backend y datos:** Node.js (Express), PostgreSQL, Prisma, .NET Core (API REST)
- **IA aplicada:** Claude Code, agentes y skills, hooks de validación, MCP
- **Calidad y despliegues:** Vitest, Jest, Playwright, Docker, GitHub Actions

## Proyectos destacados

- **[destrabe-app](https://github.com/EliabLM/destrabe-app)**: app móvil de intermediación de servicios de grúa con oferta libre. Autenticación por OTP, ciclo de vida de servicios, cotizaciones, pagos con split de comisión (MercadoPago sandbox), PostGIS y Expo.
- **[pos-system](https://github.com/EliabLM/pos-system)**: punto de venta multi-tenant con Next.js 15, Prisma y PostgreSQL. Migración incremental (strangler-fig) a monorepo, aislamiento por tenant con RLS, dinero en `numeric` y suite E2E con Playwright.

## En lo que estoy

Estructuras de datos y algoritmos, PostgreSQL a fondo, arquitectura de software, y diseño de sistemas para pagos.
